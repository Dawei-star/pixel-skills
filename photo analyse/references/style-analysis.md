# 样式分析参考指南

从网页截图中系统化提取设计令牌的方法论。

## 色彩提取策略

### 识别色彩系统

1. **背景色**：先看最大面积区域（页面背景、区块背景、卡片背景）
2. **文字色**：识别标题 vs 正文 vs 次要文字的层级
3. **品牌/强调色**：按钮、链接、激活状态、高亮元素
4. **边框色**：通常是区块/卡片之间的浅灰色
5. **遮罩色**：主视觉图片上的深色遮罩、弹窗背景

### 常见色彩模式

| 元素 | 典型色值 |
|---|---|
| 页面背景 | 白色 (#fff)、浅灰 (#f9fafb, #f5f5f5)、深色 (#111827, #0f172a) |
| 卡片背景 | 白色或比页面背景略浅/略深 |
| 主要文字 | 近黑色 (#111827, #1a1a2e, #18181b) |
| 次要文字 | 中灰色 (#6b7280, #64748b, #94a3b8) |
| 主要操作色 | 蓝色 (#3b82f6)、靛蓝 (#6366f1)、紫色 (#8b5cf6)、翠绿 (#10b981) |
| 危险/错误 | 红色 (#ef4444, #dc2626) |
| 成功 | 绿色 (#22c55e, #10b981) |
| 警告 | 琥珀色 (#f59e0b, #eab308) |
| 边框 | 浅灰色 (#e5e7eb, #d1d5db, rgba(0,0,0,0.1)) |

### 暗色模式检测

暗色主题的标志：
- 页面背景为深色（近黑色）
- 文字为浅色（白色或浅灰色）
- 卡片使用微妙的更亮背景
- 边框使用 rgba(255,255,255,0.1) 风格

## 字体排版估算

### 字体族推断

| 视觉特征 | 可能的字体族 |
|---|---|
| 干净、几何、无衬线 | Inter, SF Pro, system-ui, Segoe UI |
| 圆润、友好 | Nunito, Poppins, Quicksand |
| 技术、等宽 | JetBrains Mono, Fira Code, Source Code Pro |
| 优雅、有衬线 | Playfair Display, Merriweather, Lora |
| 现代、可变字重 | Plus Jakarta Sans, Manrope, Satoshi |

### 字号层级（桌面端）

| 元素 | 典型范围 |
|---|---|
| 展示/主标题 | 3rem - 4.5rem (48px - 72px) |
| H1 | 2.25rem - 3rem (36px - 48px) |
| H2 | 1.5rem - 2.25rem (24px - 36px) |
| H3 | 1.25rem - 1.5rem (20px - 24px) |
| H4 | 1.125rem - 1.25rem (18px - 20px) |
| 正文 | 0.9375rem - 1.125rem (15px - 18px) |
| 小字/注释 | 0.75rem - 0.875rem (12px - 14px) |

### 字重层级

- 正文：400（常规）
- 小标题：500（中等）或 600（半粗）
- 标题：600（半粗）到 800（超粗）
- 展示文字：700 到 900

## 间距估算

### 常见间距比例

**4px 基准**：4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128
**8px 基准**：8, 16, 24, 32, 40, 48, 64, 80, 96, 128

### 区块内边距（桌面端）

| 区块类型 | 典型内边距 |
|---|---|
| 标准区块 | 80px - 96px 垂直，24px 水平 |
| 大型/主视觉区块 | 96px - 160px 垂直 |
| 紧凑区块 | 48px - 64px 垂直 |
| 容器最大宽度 | 1200px - 1280px |

### 卡片内边距

| 卡片类型 | 典型内边距 |
|---|---|
| 标准卡片 | 24px - 32px |
| 紧凑卡片 | 16px - 20px |
| 大型卡片 | 32px - 48px |

## 阴影系统

### 层级体系

| 级别 | CSS 值 | 使用场景 |
|---|---|---|
| 小 | `0 1px 2px rgba(0,0,0,0.05)` | 微妙提升 |
| 中 | `0 4px 6px -1px rgba(0,0,0,0.1)` | 卡片、下拉菜单 |
| 大 | `0 10px 15px -3px rgba(0,0,0,0.1)` | 提升卡片、弹出层 |
| 超大 | `0 20px 25px -5px rgba(0,0,0,0.1)` | 弹窗、对话框 |
| 极大 | `0 25px 50px -12px rgba(0,0,0,0.25)` | 主视觉图片、主要提升 |

### 彩色阴影

用于主色元素：
```css
box-shadow: 0 10px 30px -5px rgba(主色R, 主色G, 主色B, 0.3);
```

## 圆角模式

| 元素 | 典型圆角 |
|---|---|

| 卡片 | 8px - 16px |
| 输入框 | 6px - 8px |

## 布局模式

### 常见页面布局

1. **落地页**：导航栏 → 主视觉 → 功能特性 → 用户评价 → 行动号召 → 页脚
2. **仪表盘**：侧边栏 + 顶栏 + 主内容区（卡片/网格）
3. **博客**：导航栏 → 精选文章 → 文章网格 → 侧边栏 → 页脚
4. **SaaS 产品**：导航栏 → 主视觉 → 社会证明 → 功能 → 定价 → 常见问题 → 行动号召 → 页脚
5. **电商**：顶栏 → 导航栏 → 轮播横幅 → 分类 → 商品列表 → 页脚

### 网格系统

| 列数 | 使用场景 |
|---|---|
| 2 列 | 博客文章、定价方案、用户评价 |
| 3 列 | 功能卡片、团队成员、用户评价 |
| 4 列 | 商品网格、图标功能、统计数据 |
| 12 列 | 复杂仪表盘、完整页面布局 |

### 容器宽度

| 类型 | 宽度 |
|---|---|
| 窄 | 720px - 800px |
| 标准 | 1024px - 1200px |
| 宽 | 1280px - 1440px |
| 全宽 | 100%（带内边距） |

## 视觉风格检测

### 设计风格指标

| 风格 | 特征 |
|---|---|
| 极简/清爽 | 大量留白、有限色彩、细边框、轻阴影 |
| 大胆/鲜艳 | 强色彩、大字号、渐变、高对比度 |
| 毛玻璃 | 磨砂玻璃效果、backdrop-blur、半透明背景 |
| 新拟态 | 柔和阴影（内凹+外凸）、柔和色彩、浮雕感 |
| 粗野主义 | 原始风格、粗边框、等宽字体、高对比度、非对称 |
| 企业风 | 蓝色主色、专业字体、结构化网格、微妙阴影 |
| 活泼风 | 大圆角、明亮色彩、插画、休闲字体 |

## 响应式适配规则

### 导航栏断点

| 屏幕 | 导航模式 |
|---|---|
| 桌面端 (1024px+) | 完整水平导航 |
| 平板 (768px - 1023px) | 精简导航或汉堡菜单 |
| 移动端 (< 768px) | 汉堡菜单、全屏覆盖 |

### 网格适配

| 桌面端 | 平板 | 移动端 |
|---|---|---|
| 4 列 | 2 列 | 1 列 |
| 3 列 | 2 列 | 1 列 |
| 2 列 | 2 列 | 1 列 |
| 侧边栏 + 内容 | 侧边栏折叠 | 堆叠排列 |

### 字号缩放

使用 `clamp()` 实现流式字号：
```css
h1 { font-size: clamp(2rem, 5vw, 3.5rem); }
h2 { font-size: clamp(1.5rem, 3vw, 2.25rem); }
```
