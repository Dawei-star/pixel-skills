# 校验器自测

`blindspots.svg` 是故意画坏的一张图，一次性踩满五种"局部看都对、整张看是乱"的缺陷：

| 缺陷 | 在图上的样子 |
|---|---|
| 连线横穿图元 | B 右侧出发的线横穿 D 框，落到 E 上 |
| 箭头悬空 | 有根箭头指向 (180,200) 那片空地 |
| 图元重叠 | 右上两个框压在一起 |
| 文字挤爆所在框 | "用户登录并校验权限" 撑出 100 宽的框 |
| 线跑出画布 | 顶部一条线伸到 x=470（viewBox 只到 400） |

```bash
python scripts/check_diagram.py scripts/tests/blindspots.svg
# 期望：退出码 1，至少 5 处问题
```

改动 `check_diagram.py` 的全局检查后跑这一张，报数掉到 5 以下就说明检查被改坏了。
`assets/examples/*-ok.svg` 全部 11 张必须报 0 —— 那是误报的底线。
