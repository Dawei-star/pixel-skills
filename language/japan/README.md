# Pixel Skills

[简体中文](../../README.md) · [English](../en/README.md) · **日本語** · [한국어](../korea/README.md)

> 参照物はある。それでも仕上がりは崩れる。

論文の図には国家規格があるのに、出来上がりはバラバラ。デザインの色値はそこにあるのに、再現すると色が一段ずれる。原因は規格を知らないことではなく、誰も一つずつ突き合わせていないこと——人は「だいたい合っている」に甘すぎる。

この二つの skill は、規格を実行できる形に変えます。ルールは `SKILL.md` に、判定できるものはスクリプトに、測れるものは数値に。**受け持つのは形・寸法・書式まで。中身が正しいかは、ご自身で見てください。**

## 収録内容

### [thesis-diagram](../../thesis-diagram/) — 論文図の生成と検査

- **読む** [オンラインマニュアル](https://www.axxiu.cn/project/GAIe9QK1/) → 6 種類の図の記号定義、正誤対照、提出前チェックリスト
- **言う** `ユースケース図を描いて` → GB 1526 / UML 2.5 に沿ったソースを出力
- **言う** `このフローチャートは規格に合ってる?` → 矢印の接続、文字のはみ出し、端子の形をスクリプトで検査
- **付属** 正誤例 20 点。独立した SVG で、座標はそのまま流用できる

### [webpage-cloner](../../webpage-cloner/) — スクリーンショットからフロントエンドコードへ

- **読む** [オンラインマニュアル](https://www.axxiu.cn/project/hm0v82sg/) → 色と余白の測り方、正誤対照、納品前チェック
- **言う** `このスクショを再現して` → 配色・書体・余白を抽出
- **言う** `このデザインをコードにして` → そのまま開ける HTML/CSS/JS を出力
- **付属** コンポーネント雛形とスタイル分析ガイド

## インストール

コマンド 1 行。Node が必要です——`npx` は Node に同梱されています。

### Claude Code / Codex / その他

```bash
npx skills add Dawei-star/pixel-skills -g
```

`-g` を付けるとユーザー単位で入り、すべてのプロジェクトから使えます。付けなければ現在のプロジェクトだけ。導入済みのエージェントは自動で検出され、Cursor、Gemini CLI、Copilot、Windsurf などに対応しています。明示するなら `-a claude-code`、複数はスペース区切り。

先に中身を確認するなら `npx skills add Dawei-star/pixel-skills --list`。更新は `npx skills update`。

### 現在のプロジェクトだけに入れる

`npx skills add` を `-g` なしで実行します。

## 新しい skill を書く

`SKILL.md` は流れと索引だけにして、細部は `references/` と `assets/` に分けます。

`description` には発火条件を書きます——ユーザーが実際に口にする言葉を入れてください。YAML の折り返しブロック（`>`）は使わないこと。検証器によっては `>` を山括弧と誤読します。

ディレクトリ名は `SKILL.md` の `name` と一致させます。小文字・数字・ハイフンのみ。一致していなくても多くのツールはエラーを出さず、ただ黙って見つけられなくなります。
