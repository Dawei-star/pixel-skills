## 插件市场化（用户嫌 cp -r 太土）

- 用户拿 mattpocock/skills 的 README 对比，要求安装段做成一行命令。核心不是抄格式，
  是仓库得先具备 marketplace 清单。
- 新增 `.claude-plugin/marketplace.json`，marketplace 名 `dawei-skills`，
  两个 plugin：`thesis-diagram`（source `./thesis-diagram`）、
  `webpage-cloner`（source `./photo analyse`，带空格也行）。
- **关键机制**：plugin 根目录直接有 `SKILL.md`、没有 `skills/` 子目录时，
  Claude Code 把它当**单个 skill** 加载。所以仓库不用重构目录就能当 plugin 用。
- 实测结论（本机 claude 2.1.158 / codex 均有 plugin 子命令）：
  - `claude plugin marketplace add Dawei-star/Skills` ✅
  - `claude plugin install <name>@dawei-skills` ✅（两个都装上，scope: user）
  - `claude plugin marketplace update [name]` 存在，**没有**自动更新
  - `codex plugin marketplace add` ✅ 能读 `.claude-plugin/marketplace.json`
  - `codex plugin install` ❌ 不存在——这个版本的 codex 只有
    `plugin marketplace {add,upgrade,remove}`，装完要在面板里勾选。
    mattpocock README 里那条 `codex plugin install` 在本机跑不通，别照抄。
- WorkBuddy 没有命令行装插件的入口（marketplace 只支持 zip / directory source，
  且需在 UI 里添加），所以 README 里 WorkBuddy 那节只能保留 `cp -r`。
